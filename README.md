# FISK — NGO Intelligence Hub

An AI-powered press monitoring, funding research, and email alerting system for NGOs working in Burundi and global animal welfare.

## How to run this project

You need **two terminals running simultaneously** — the backend serves the API, the frontend consumes it.

### 0. Setup (first time only)

```bash
cd "Python pipeline"
cp .env.example .env
```

Open `.env` and fill in real values:

| Variable | Required | Description |
|----------|----------|-------------|
| `OPENAI_API_KEY` | Yes | Your OpenAI API key (used for summarization, translation, extraction) |
| `GMAIL_IMAP_USER` | For email ingestion | Gmail address with Google Alerts configured |
| `GMAIL_APP_PASSWORD` | For email ingestion | 16-char Gmail App Password (not your regular password) |
| `OPENAI_MODEL` | No | Defaults to `gpt-4o-mini` |
| `ALERT_SINCE_DAYS` | No | How many days back to scan emails (default: 7) |

> **⚠️ This `.env` file contains real secrets and is excluded from the repo via `.gitignore`. Never commit it.**

If you skip the Gmail credentials, the pipeline still runs — it just skips email ingestion with a warning.

### 1. Backend (Python pipeline + Flask API)

```bash
cd "Python pipeline"
python run_all.py
```

This runs the full pipeline in order:
1. Scrapes news RSS feeds, funding listings, and Google Alert emails
2. Summarizes everything via OpenAI (bilingual EN/DE)
3. Exports unified data to `Loveable pipeline/data/items.json`
4. Starts the Flask API server on `http://localhost:5000`

**To skip re-scraping** and just re-summarize/export/serve on already-ingested data:

```bash
python run_all.py --skip-ingest
```

**Requirements:**
- Python 3.11+
- `pip install -r requirements.txt`
- `.env` file with `OPENAI_API_KEY` (and optionally `GMAIL_IMAP_USER` + `GMAIL_APP_PASSWORD` for email ingestion)

### 2. Frontend (React + Vite)

In a **separate terminal**:

```bash
cd "Loveable pipeline"
bun install        # first time only
bun run dev
```

Opens at `http://localhost:5173`. The frontend fetches live data from the backend API at `localhost:5000`.

**Requirements:**
- [Bun](https://bun.sh/) (or Node 18+ with `npm` instead of `bun`)

### Both must be running

The frontend shows "Failed to load items" if the backend isn't running. Start the backend first, then the frontend.

## Project structure

```
FISK/
├── Python pipeline/     # Data ingestion, AI summarization, Flask API
│   ├── ingest.py        # RSS news scraping
│   ├── ingest_funding.py # Funding listings scraping
│   ├── ingest_inbox.py  # Google Alert email ingestion
│   ├── summarize_funding.py # Funding AI extraction
│   ├── app.py           # Flask server (news/email summarization + dashboard)
│   ├── export_items.py  # Unified JSON export for frontend
│   └── run_all.py       # Full pipeline orchestrator
├── Loveable pipeline/   # React frontend (TanStack Router + Tailwind)
│   ├── app.py           # Flask API serving items.json to frontend
│   ├── src/             # React components and routes
│   └── data/items.json  # Generated by export_items.py (gitignored)
├── run_all.py           # Top-level pipeline runner
└── README.md
```
